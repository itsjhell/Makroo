# Makroo 🖱⏺

Autoclicker + macro recorder for Windows, all in one program.

## Launch

Double-click **`Avvia Makroo.bat`** (or run `python makroo.py` from a terminal).

Requirements: Python 3 with the `pynput` library (`pip install pynput`).

## Autoclicker mode 🖱

- **Interval** between clicks in milliseconds, seconds, minutes or hours
- **Left or right** button, **single or double** click
- **Repetitions**: fixed number of clicks or infinite loop
- **Position**: current cursor position or fixed coordinates (with the *Pick point…* button just click anywhere on the screen to set them)
- **Hotkeys**: customizable start/stop — default **F6** (same hotkey = start/stop toggle, OP Autoclicker style)

## Macro mode ⏺

- Records keyboard + mouse clicks; tick the option to record **mouse movements** too
- Play the recording **N times or in an infinite loop**
- **Playback speed**: 0.25x, 0.5x, 1x, 2x, 4x or custom
- **Save** the macro to a `.json` file and **load it back** anytime
- **Hotkeys**: customizable — default **F7** (record/stop) and **F8** (play/stop)

## Notes

- Hotkeys work globally, even when Makroo is in the background, and can also be **mouse buttons** (e.g. side buttons Mouse 4/5).
- **Hotkeys only act on the tab currently shown**: autoclicker hotkeys are ignored while the Macro tab is active and vice versa, so you can safely assign the same keys to both modes.
- The **"Always on top"** checkbox keeps the window above all others.
- The program's own hotkeys are **never recorded** into macros, and clicks generated by Makroo never trigger hotkeys nor get re-recorded.
- All settings (hotkeys included) are saved to `makroo_config.json` on exit and restored on the next launch. The last selected tab is remembered too.
- If playback is stopped midway, any keys still held down are released automatically (no "stuck" keys).
